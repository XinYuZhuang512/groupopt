## Pointer Network 状态特征消融补充

完整状态被拆分为组件均值、路径起点和组件规模，并加入参数匹配的静态对照。
2,000-step 筛选后，将组件均值和路径起点续训至 10,000 steps。seed 1234 上，
路径起点的独立测试 cost 为 6.339969，与 fixed 的 6.341167 统计持平，但优于
完整状态的 6.383866。

随后仅对路径起点补充 seeds 2345、3456、4567。四个种子的独立测试均值为
6.363053，对应 fixed 均值为 6.313310，平均落后 0.049743（约 0.79%），仅在
1/4 seed 上胜出且该胜局近似持平。因此停止 Pointer Network 路径起点分支：
它能修复完整状态的一部分退化，但不能稳定胜过 fixed。下一模型转向 Graph
Pointer Network。

## Graph Pointer Network：多种子确认

GPN 的 2,000-step pilot 筛除朴素 adaptive 后，将 fixed 与 adaptive_state 续训
至 10,000 steps。seed 1234 的独立测试 cost 分别为 6.224794 和 6.206470；
adaptive_state 改善 0.018324（约 0.29%），同实例配对 95% CI 为
`[-0.024229, -0.012420]`。随后按完全相同的配置补充 seeds 2345、3456、
4567，并将最佳 checkpoint 统一评估在同一批 10,000 个测试实例上。

| 训练 seed | fixed | adaptive_state | state - fixed |
| ---: | ---: | ---: | ---: |
| 1234 | 6.224794 | 6.206470 | -0.018324 |
| 2345 | 6.214851 | 6.205075 | -0.009776 |
| 3456 | 6.225643 | 6.242013 | +0.016370 |
| 4567 | 6.219362 | 6.227356 | +0.007995 |
| mean | 6.221163 | 6.220228 | -0.000934 |

adaptive_state 仅在 2/4 个训练 seed 上胜出，四 seed 平均改善约 0.015%。
训练-seed 层面配对差异的 95% CI 为 `[-0.0263, 0.0244]`，几乎以零
为中心。因此 seed 1234 的正向结果不能解释为 GPN 上的稳定优势；
当前机制可以跨模型运行，但收益仍具有明显的模型依赖性。
