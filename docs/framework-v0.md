# 群论构造框架 v0

## 1. 一句话主张

我们提出一种**群作用驱动、模型无关的组合解构造框架**：用群作用、稳定化子链和问题约束定义“如何逐步生成一个解”，把神经模型限制为候选动作的评分器，从而让同一构造过程能够接入不同模型。

这里的“通用”首先指**跨模型**，不指跨搜索或求解策略。第一阶段固定采用逐步采样或贪心构造，不同时讨论 beam search、局部搜索、MCTS 等策略。

## 2. 必须区分的三个层次

### 2.1 框架层

框架规定每一步有哪些候选对象、选择后稳定化哪个对象、有哪些陪集代表元、哪些动作因问题约束而非法，以及怎样把动作序列解码为组合解。

### 2.2 问题实例化层

TSP、固定环数问题和 VRP 分别给出自己的状态、约束遮罩、转移和目标函数。它们是框架的实例，而不是框架本身。

### 2.3 模型层

MLP、GNN、Attention Model 或 Transformer 只负责给当前候选动作打分。模型不负责维护可行性，也不拥有问题状态转移逻辑。

因此依赖关系是：

```text
问题实例 -> 群论构造规范 -> 候选动作与遮罩 -> 模型评分 -> 状态转移 -> 完整解
```

## 3. 优化问题的基本对象

对每个问题实例 \(I\)，记：

- \(\mathcal F(I)\)：可行解集合；
- \(c_I:\mathcal F(I)\to\mathbb R\)：目标函数；
- \(G_I\)：用于表示解或解的生成过程的有限群；
- \(X_I\)：\(G_I\) 作用的对象集合。

框架不要求所有问题共享同一个群，但要求每个问题实例给出一个明确的群作用及其组合语义。

## 4. 群论构造规范

在第 \(t\) 步，构造状态写成

\[
s_t=(q_t,H_t,h_t),
\]

其中：

- \(q_t\) 是问题层的部分解，例如若干条尚未闭合的路径；
- \(H_t\le G_I\) 是当前剩余对称性对应的子群；
- \(h_t\in G_I\) 是目前已选择代表元的乘积。

一次构造动作分成两个部分：

1. 从 \(B(s_t)\) 中选择本步要稳定化的对象 \(b_t\)；
2. 令 \(H_{t+1}=\operatorname{Stab}_{H_t}(b_t)\)，再从一个陪集代表元集合
   \(R(s_t,b_t)\) 中选择 \(r_t\)。

随后执行

\[
s_{t+1}=T_I(s_t,b_t,r_t),\qquad h_{t+1}=h_t r_t.
\]

问题约束通过合法性函数

\[
M_I(s_t,b_t,r_t)\in\{0,1\}
\]

过滤动作。终止时由解码函数 \(D_I(s_T,h_T)\) 输出 \(y\in\mathcal F(I)\)。

这个定义允许两种构造方式：

- **固定基方式**：\(b_t\) 的顺序预先给定，模型只选择 \(r_t\)，对应许多已有的顺序解码算法；
- **自适应基方式**：模型同时选择 \(b_t\) 和 \(r_t\)，对应原始想法中的“双机器学习选择”。

“固定基”与“自适应基”是同一框架的两个配置，而不是两个互不相关的算法。

## 5. 模型接口

模型只能访问实例表示、当前状态摘要和候选集合，并返回 logits：

```python
class ConstructionModel:
    def encode(self, instance): ...

    def score_bases(self, encoding, state, candidates): ...

    def score_representatives(
        self, encoding, state, selected_base, candidates
    ): ...
```

固定基方式不调用 `score_bases`。框架统一完成 softmax、遮罩、动作选择、状态转移和解码。

跨模型的操作性判据是：替换 `ConstructionModel` 的实现时，不修改问题状态、合法动作、转移函数和解码函数。

## 6. 第一个实例：TSP 的自适应基构造

### 6.1 置换表示

一个有向 TSP 解可以表示为一个 \(n\)-轮换 \(\sigma\in S_n\)，边集合为

\[
\{(i,\sigma(i)):i\in[n]\}.
\]

普通置换可能包含多个不相交的环，而 TSP 要求最终只有一个环。

### 6.2 部分解状态

部分解 \(q_t\) 是若干条互不相交的有向路径。每个连通分量维护：

- `head`：入度为 0 的起点；
- `tail`：出度为 0 的终点；
- 该分量包含的节点集合或其并查集标识。

初始时每个节点都是一条长度为 0 的路径，同时是自己的 `head` 和 `tail`。

### 6.3 动作与遮罩

一次动作选择一对 \((x,y)\)：

- \(x\) 从所有 `tail` 中选择，对应本步自适应选择的基元素；
- \(y\) 从所有 `head` 中选择，对应确定 \(\sigma(x)=y\) 的代表元选择；
- 若尚有多个路径分量，禁止选择与 \(x\) 属于同一分量的 \(y\)，以免提前形成子环；
- 当只剩一个路径分量时，唯一的最后动作连接其 `tail` 与 `head`，形成 Hamilton 环。

转移操作加入边 \(x\to y\)，并合并这两条路径。

### 6.4 基本性质

实现必须验证以下性质：

1. **保持可行延拓**：任一合法中间状态都可以继续完成；
2. **终止可行性**：执行完恰好得到每点入度、出度均为 1 的单个环；
3. **完备性**：任意有向 Hamilton 环都至少能由一条合法动作序列生成；
4. **有限终止**：前 \(n-1\) 步合并不同分量，最后一步闭环；
5. **群论一致性**：部分映射和最终置换与选定群作用、稳定化子链及代表元乘积一致。

前三项可以先做程序性质测试，第五项需要单独给出严格命题和证明。

## 7. 一个不能忽略的问题：同解多轨迹

自适应选择 \(x\) 后，同一个 Hamilton 环通常可以由多种边添加顺序生成。因此“动作轨迹”到“最终解”一般不是一一映射。

这会带来两个后果：

- 使用强化学习、只按最终目标评价采样轨迹时，这种多重表示原则上可直接处理；
- 使用给定最优解做最大似然训练时，必须指定规范构造顺序，或对多个潜在顺序进行边缘化，不能把某一个任意顺序误当成唯一标签。

第一版实验建议固定训练策略，先采用基于最终 tour cost 的策略梯度，避免在同一阶段引入监督轨迹规范化问题。

## 8. 第一轮实验应检验什么

第一轮实验采用一个 \(2\times2\) 设计：

| 构造方式 | 模型 A | 模型 B |
| --- | --- | --- |
| 固定基（顺序选择下一节点） | 运行 | 运行 |
| 自适应基（选择 `tail` 与 `head`） | 运行 | 运行 |

模型 A 和 B 应具有明显不同的架构，例如轻量图网络与 Transformer/Attention 编码器，但共享同一训练策略和尽可能一致的参数规模。

至少记录：

- 最终解合法率；
- tour length 和相对最优差距；
- 推理时间、模型调用次数和显存；
- 训练稳定性；
- 从训练规模到更大规模的泛化；
- 固定基与自适应基之间的差异是否在两个模型上方向一致。

其中“两个模型无需改变构造逻辑即可运行”验证跨模型性；性能是否提升是独立的经验问题，不能预先写成结论。

## 9. 当前最小科学主张

第一篇实现不必同时覆盖 TSP、固定环数问题和 VRP。最低但完整的主张可以是：

> 稳定化子链给出了一种将组合解构造语义与神经评分模型分离的方法；固定基和自适应基解码均可在同一接口下表达，并能在不同神经模型上复用。TSP 的路径合并实例保证输出可行，且自适应基选择带来不同于传统固定顺序解码的构造空间。

后续扩展到固定环数、多环目标和 VRP，才用于支持更强的跨问题主张。

## 10. 暂不纳入第一版的内容

- 不同搜索策略之间的统一；
- \(S_n\curvearrowright[n]^k\) 的并行多边构造；
- \(S_n\) 上的共轭作用方案；
- 固定环数、未知环数与 VRP 的完整实现；
- “适用于所有组合优化问题”一类过强表述。

这些内容保留为扩展方向，避免第一版同时承担过多理论与工程风险。
