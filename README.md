# GroupOpt

一个面向组合优化的、跨模型的群论构造框架研究项目。

## 当前研究边界

- 用群作用及其稳定化过程统一描述组合解的逐步构造。
- 将状态、合法动作、状态转移和解码规则从具体神经网络中分离。
- 同一套构造接口可以接入多个模型并进行对照实验。
- 当前阶段不追求跨求解策略；先固定为逐步构造式求解。

## 目录

- `src/groupopt/`：框架核心实现
- `tests/`：单元测试与性质测试
- `experiments/`：实验配置和运行入口
- `docs/`：数学定义、设计决策和实验方案

旧目录中的已有项目仅作为外部参考，不属于本仓库，也不纳入本仓库的版本管理。

## 当前进度

- 已定义模型无关的两阶段构造接口；
- 已实现 TSP 的自适应基路径合并状态机；
- 已实现固定基顺序解码在同一状态机中的嵌入；
- 已通过小规模完备性和可行性的穷举测试。
- 已接入 AM-style 图注意力模型，并跑通采样、反向传播和最小 REINFORCE 训练。

PYTHONPATH=src python3 -m unittest discover -s tests -v
